## Learning Path

A suggested progression:

1. Start with **Bluenet Lab: Virtual Networking 101** to become familiar with virtual network concepts.
2. Continue with **Blue Pulse Discovery** and **Netdiscover on the Blue Wire**.
3. Explore **Blueshift Fingerprinting**, **Bluescan Version Sleuth**, and **Nmap Recon Blueprint**.
4. Prepare the Drip environment with **Drip Drop Lab Setup**, then explore **Drip Crack Root**.
5. Study the Corrosion-themed labs to understand their chain-based challenge focus.
6. Finish with the Tomcat and Python module abuse labs to explore the privilege-escalation theme.

## How to Use the Labs

1. Open each lab using its direct Learn SecByte link.
2. Read the lab scope and instructions before starting.
3. Perform all activities only in the authorized lab environment.
4. Keep notes on network observations, discovered services, clues, and configurations.
5. Focus on understanding the security concepts behind each exercise.
6. Document lessons learned for future CTF and defensive-security practice.
